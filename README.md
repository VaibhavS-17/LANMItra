# 🎮 LANMitra

**Your Gateway to Local Gaming Tournaments & Café Bookings**

LANMitra is a platform that connects gaming café owners, tournament organizers, and players. Book PC/console stations at top cafés, compete in tournaments with auto-generated brackets, and track live leaderboards — all in one place.

---

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or later)
- npm (comes with Node.js)

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/LANMitra.git
cd LANMitra

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at `http://localhost:5173`

### Build for Production

```bash
npm run build
npm run preview
```

---

## 🎯 Features

- **Café Station Booking** — Browse gaming cafés, check real-time availability, and book PC/console stations
- **Tournament Management** — Create and join single-elimination tournaments with automatic bracket generation
- **Match & Result Tracking** — Report results, auto-confirm matches, and resolve disputes
- **Live Leaderboards** — Track tournament standings and bracket progress in real-time
