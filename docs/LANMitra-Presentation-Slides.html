IDEA / APPROACH DETAILS

From Chaotic Calls to Seamless Clicks
Core Mission: LANMitra is a unified platform connecting café owners, tournament organizers, and players. It eliminates phone-call double bookings and automates bracket generation with dispute-free match reporting.

🎮 1. Station Booking Engine

Browse cafés, inspect PC specs (GPUs, refresh rates), and lock in guaranteed 1-hour slots with zero double-booking.

🏆 2. Auto-Bracket Generation

Organizers create tournaments; brackets auto-generate with automatic bye handling for arbitrary participant counts.

⚔️ 3. Dual-Result Verification

Both players report match scores independently; matching results auto-advance, discrepancies flag instant disputes.

📊 4. Live Leaderboards

Real-time tournament progression and standings matrix accessible on mobile and desktop without manual paperwork.

HOW IT ADDRESSES THE PROBLEM: Browse Cafés ➔ Book Station ➔ Compete in Tournament ➔ Verify Results ➔ Live Standings

TECHNICAL APPROACH

Enterprise 3-Tier Architecture

🏗️ Architecture & Conflict Engine

Deterministic SQL verification guarantees 100% immunity from concurrent double-booking:

SELECT COUNT(*) FROM bookings
WHERE station_id = :id AND booking_date = :date
AND status = 'CONFIRMED'
AND start_time < :endTime AND end_time > :startTime;

🔒 Security & Roles

Spring Security 6 with stateless JWT Bearer authentication and BCrypt password hashing. Role-Based Access Control (RBAC) across Player, Café Owner, Organizer, Admin.
