Overview

About LANMitra

Traditional gaming cafes and local tournaments rely on fragmented phone calls, WhatsApp chats, and spreadsheets. LANMitra solves this with automated scheduling, verified match reporting, and single-elimination tournament management.

🎮

For Players

Discover verified gaming cafes, view real-time station availability, reserve PC/console slots, and register for upcoming competitive tournaments.

  • Instant slot reservation
  • Live tournament brackets
  • Fair match score reporting
🖥️

For Cafe Owners

List gaming stations with hardware specifications, manage pricing per hour, and eliminate double-booking conflicts with automated schedule locking.

  • Station & hardware inventory
  • Overlap prevention algorithm
  • Real-time booking calendar
🏆

For Organizers

Host single-elimination tournaments with automatic seeding, bracket generation, bye handling, and official dispute resolution mechanisms.

  • Automated bracket progression
  • Live tournament leaderboards
  • Dispute arbitration panel
Capabilities

Core Platform Features

Designed to meet academic requirements for Full Stack Java Programming (FSJP), focusing on robust data integrity and user satisfaction.

01

Station Booking Engine

Allows users to select date, time slots, and hardware tiers. The platform enforces strict concurrency checks to guarantee zero overlapping reservations.

02

Automated Brackets

Generates single-elimination tournament trees automatically upon registration closing. Automatically allocates byes when participant counts are not powers of two.

03

Result Tracking & Disputes

Both competing players submit match outcomes. Matching scores advance the bracket automatically; conflicting reports are flagged for organizer review.

04

Live Leaderboards

Real-time standings and match history views allow spectators and participants to track bracket progression, match winners, and tournament champions.
